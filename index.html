Ouncehub 隐私政策

适用范围为 Ouncehub Garmin Connect IQ 手表应用。该应用从配置的行情服务获取黄金、白银与汇率数据，并在手表上显示报价。

应用设置和设备缓存

应用读取填写在 Connect IQ 应用设置中的行情地址和 API 密钥，并保存品种偏好和最近一次成功获取的报价，以便显示手表上的概览。报价缓存不包含 API 密钥。通过 Garmin 配置与同步设置时，适用 Garmin 的隐私政策。

向行情服务发送的内容

应用发起报价请求时，把对应的 API 密钥放在 x-api-key 请求头中，用于向配置的行情服务认证。启用备用接口且没有填写单独的备用密钥时，备用接口也会收到主接口的密钥。行情服务可能记录网络请求和认证信息，具体记录及保留方式取决于该服务的运营方。可用时请使用 HTTPS 行情地址。

应用访问的数据

Ouncehub 不读取 Garmin 账户资料、定位、健康数据、联系人或设备标识。应用代码没有内置广告或分析模块。

管理设置和联系开发者

你可以在 Connect IQ 的 Ouncehub 设置中更改行情地址和密钥，也可以卸载应用以停止后续报价请求。关于 Ouncehub 的隐私问题，请通过 Connect IQ 应用详情页上的联系邮箱与开发者联系。
